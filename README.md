# Stock Opname System

Sistem terintegrasi untuk mempercepat proses stock opname di retail dengan:
- 📱 Mobile app (React Native) untuk barcode scanning & input stok fisik
- 🌐 Web dashboard (Next.js) untuk monitoring & laporan
